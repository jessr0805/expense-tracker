# Expense Tracker
A Python-based expense tracker built for all users, whether they are looking for a minimalistic way to track their expenses, or users just wanting to have fun.
## Cool Features 
- **Category Tagging**
- **Automatic Export to JSON**
- **Crash-Proof Input Validation**
- **Real-Time Balance Calculations**
## How to Run It
Ensure Python is installed
If it isn't visit the 
[Official Python Installer Link](https://www.python.org/downloads/)
To run the tracker directly in the terminal,
- Clone the repository
- Navigate to the repository in your terminal
- Run
  ```bash
  python tracker.py
  ```
